# 计划生成

将用户用自然语言表达的目标，拆解成 Plan + Task 并写入存储。

## 流程

1. 从用户消息中提取三项信息：**目标**、**开始日期**、**截止日期**
2. 如果缺少日期，追问用户明确后再继续
3. 调用 `plan.create` 创建计划，description 中写明起止日期
4. 将目标拆解为 **3~8 个可执行任务**
5. 根据返回的 plan id，在开始日期到截止日期范围内均匀分配每个任务的 `date`
6. 逐个调用 `task.create` 创建任务

## 拆解规则

- 任务按执行顺序排列，从准备到收尾
- 第一个任务安排在开始日期，最后一个任务安排在截止日期
- 剩余任务在起止日期之间均匀分布
- 关键路径上的任务标记 `priority: high`，其余 `medium`
- 每个任务只分配一天

## 示例

用户输入：6月3号到6月12号完成登录模块重构

1. 提取：目标=登录模块重构，开始=6/3，截止=6/12
2. plan.create title="登录模块重构" description="起止：2026-06-03 ~ 2026-06-12"
3. 拆解：

| 任务                | 日期  | 优先级 |
| ------------------- | ----- | ------ |
| 梳理现有登录逻辑    | 06-03 | high   |
| 设计新认证接口      | 06-04 | high   |
| 实现 Token 刷新机制 | 06-05 | high   |
| 编写单元测试        | 06-06 | medium |
| 前端联调            | 06-09 | high   |
| 回归测试            | 06-11 | medium |
| 上线发布            | 06-12 | high   |
